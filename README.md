# Martian Map

Интерактивный атлас поверхности Марса на основе картографических данных NASA Solar System Treks. Позволяет исследовать видимый рельеф, карту высот MOLA, дневные и ночные инфракрасные мозаики THEMIS, а также места посадки исследовательских аппаратов.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте в браузере: <http://localhost:8000>.

Для загрузки тайлов NASA WMTS и библиотеки Leaflet требуется доступ к сети. Ключ API NASA не требуется.

## Картографические слои NASA

- **Viking MDIM 2.1 Color Mosaic** (232 м/пикс) — глобальная оптическая мозаика видимого диапазона.
- **MOLA Color Hillshade** (463 м/пикс) — теневой рельеф и карта высот лазерного альтиметра MGS MOLA.
- **THEMIS Day IR Controlled Mosaic** (100 м/пикс) — дневная тепловая инфракрасная съемка (орбитальный аппарат 2001 Mars Odyssey).
- **THEMIS Night IR Controlled Mosaic** (100 м/пикс) — ночная инфракрасная съемка теплофизических свойств поверхности.

Посадочные площадки исследовательских аппаратов Perseverance, Curiosity, InSight и Phoenix нанесены на карту с точными координатами.

## Структура проекта

- `index.html` — разметка интерфейса и картографического окна.
- `style.css` — стили, адаптивная верстка и оформление.
- `script.js` — инициализация карты Leaflet, интеграция NASA WMTS, переключение слоев, поиск и информация об объектах.
